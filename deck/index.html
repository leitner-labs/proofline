Open Agent Hackathon 2026 · Track 02 · Leitner Labs

Proofline.

An agent that answers high-stakes questions with a verifiable evidence trail. Every claim links back to the exact rows it came from.

The problem

Agents answer confidently. They cite vaguely.

  • "Switch suppliers" — says who, from what data, when?
  • High-stakes decisions need proof, not prose
  • Today the evidence is a log file nobody reads
The contract

A claim ships only with evidence.

claim → evidence rows → source → query lineage → retrieval time
  • Unverifiable claims never ship — filtered before the answer is composed
  • Every citation is clickable in the UI and printable in the CLI
The demo

"Should we switch our oat-milk supplier?"

  • Meridian Roast Co. — 6 cafes, one decision, three fragmented sources
  • SQLite purchase ledger + quality tests · CSV price lists + certifications · web recall notices
  • Answer: 8 verified claims, 14 evidence refs, zero hand-waving
The product

See it work.

Ask in plain language. Every claim arrives with its verdict, confidence and a one-click evidence trail: source, rows, lineage, query, retrieval time.

Architecture

How it works.

question → decompose → federated queries (lineage-stamped)
        → extract claims → VERIFY (evidence or drop)
        → compose → remember (H-MEM episode + trust ledger)
Sponsor technology

Built on the stack.

  • Meterless H-MEM — memory with provenance + audited trust ledger; conformance 13/13 in-repo
  • NVIDIA Nemotron — composition and judging models (OpenAI-compatible endpoint)
  • Zetaris pattern — query-in-place federation, lineage on every query; drops onto a live Zetaris endpoint by config
Why it wins

Verifiability as the product.

  • Impact: decisions people can defend (30)
  • Technical: evidence-gated claims, audited memory (20)
  • Innovation: explain-why as a first-class surface (15)
What's next

From demo to daily driver.

  • Point the federation layer at a live Zetaris endpoint — config, not code
  • Race Nemotron models; let H-MEM dreaming propose risk hypotheses overnight
  • Proofline — an agent that can explain why.
